# 스토어 등록 메모

## 기본 정보

- 이름: 치지직 채팅 커스텀
- 짧은 설명: 치지직 채팅창의 표시·스타일, 나만 보는 채팅·미니 채팅창과 주 영상 오디오를 내 브라우저에서 조정합니다.
- 단일 목적: 치지직 시청 화면의 채팅 UI와 주 영상 오디오를 사용자의 브라우저 안에서 보기·듣기 편하게 조정합니다.

## 상세 설명

치지직 채팅창에서 닉네임, 배지, 타임스탬프와 랭킹·승부예측 같은 채팅 외 패널의 표시를 각각 켜고 끌 수 있습니다. 채팅별 둥근 박스와 색상, 채팅·닉네임 글씨 크기, 굵기, 배경에 맞춘 글자색 자동 보정, 직접 고른 글자색 또는 닉네임 색을 메시지에 적용하는 기능도 제공합니다.

채팅창 모드는 치지직 기본 채팅, 나만 보는 채팅, 미니 플로팅 채팅 중에서 선택할 수 있습니다. 미니 채팅은 위치·크기·배율·최소화 및 전체화면에서만 표시할지 여부를 조정할 수 있고, 채팅 헤더의 나만 보기 전환·미니 채팅·설정 버튼은 각각 표시 여부를 선택할 수 있습니다. 나만 보는 채팅 iframe은 쿠키를 공유하지 않는 격리된 프레임으로 열고, 현재 라이브 페이지에서 감지한 테마 값만 받아 화면 색상을 맞춥니다. 사용자가 입력한 로컬 메시지는 실제 전송 경로와 분리되어 다른 사용자에게 보이지 않으며, 모드를 끄거나 페이지를 새로고침하면 사라집니다.

오디오 개선을 켜면 치지직 주 영상의 소리를 브라우저 안에서 더 편안하고 고르게 조절합니다. `자연스럽게`, `균형`, `강하게` 프리셋과 보정 음량 및 고급 설정을 제공하며, 기능을 끄면 원음 경로로 돌아갑니다. 음성을 녹음하거나 외부로 전송하지 않습니다.

모든 변경은 사용자의 브라우저 안에서만 적용됩니다. 실제 방송, 채팅 서버, 채팅 메시지 삭제/차단/moderation 동작에는 영향을 주지 않습니다.

이 확장프로그램은 네이버 또는 치지직의 공식 앱이 아니며, 네이버/치지직과 제휴되거나 승인된 도구가 아닙니다.

## 권한 설명

- `storage`: 표시 설정을 로컬 저장소에 저장하고, 랜덤 닉네임 대응 관계를 탭 종료까지 세션 저장소에 보관합니다.
- `https://chzzk.naver.com/*`: 치지직 라이브 페이지와 같은 출처의 채팅 프레임에서 로컬 UI 표시와 주 영상 오디오 설정을 적용합니다.

`activeTab`, `scripting` 권한과 치지직 하위 도메인 전체 권한은 사용하지 않습니다.

## 개인정보 답변

- 개발자의 개인정보 수집: 없음. 랜덤 닉네임 사용 시 화면의 닉네임·별명 대응 관계는 탭 종료까지 브라우저 메모리에서만 처리합니다.
- 사용자 데이터 외부 전송: 없음
- 제3자 제공/판매: 없음
- 원격 코드 사용: 없음
- 오디오 녹음/저장/전송: 없음
- 설정 저장 위치: 브라우저 로컬 확장 저장소 및 초기 깜빡임 감소용 치지직 페이지 로컬 캐시
