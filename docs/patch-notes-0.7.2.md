# 치지직 채팅 커스텀 0.7.2 패치 노트

릴리즈일: 2026-07-26

이번 버전은 브라우저에서만 적용되는 오디오 개선 기능을 더 쉽게 사용할 수 있도록 정리하고, `나만 보는 채팅`의 테마가 실제 화면 색상과 어긋나는 문제를 수정했습니다.

## 오디오 개선

- 기능 이름과 안내 문구를 `오디오 압축`에서 `오디오 개선`으로 통일했습니다.
- 빠른 설정에서 `자연스럽게`, `균형`, `강하게` 프리셋을 선택할 수 있습니다.
- 고급 설정은 의미를 바로 이해할 수 있도록 쉬운 표현과 설명을 함께 표시합니다.
- 보정 음량 기본값을 `100%`로 조정했습니다.
- 세부 기본값은 다음과 같습니다.
  - 개선 시작 음량: `-50dB`
  - 개선 적용 방식: `40dB`
  - 큰 소리 억제 강도: `12:1`
  - 반응 속도: `0초`
  - 복귀 속도: `0.25초`
- 오디오 처리는 브라우저 안에서만 동작하며, 기능을 끄면 원래 소리로 돌아갑니다.

## 나만 보는 채팅 테마

- 부모 화면에서 감지한 최신 라이트·다크 테마를 나만 보는 채팅에 안정적으로 반영합니다.
- 초기 URL 테마가 이후에 전달된 현재 테마를 덮어쓰지 않도록 수정했습니다.
- 치지직이 실제 색상 변수를 선택할 때 사용하는 `data-theme` 속성까지 동기화해, 테마 이름과 화면 색상이 서로 어긋나지 않도록 했습니다.
- 페이지가 테마 속성을 다시 바꾸는 경우에도 주기 동기화와 재시도로 현재 테마를 복구합니다.

## 릴리즈 패키지

- 확장 프로그램 버전을 `0.7.2`로 올렸습니다.
- 배포 ZIP에 오디오 개선 스크립트와 필요한 아이콘·팝업 파일이 모두 포함되도록 패키징을 보완했습니다.
- 전체 회귀 테스트 34개와 확장 패키지 검증을 통과했습니다.
