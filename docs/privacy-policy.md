# 개인정보 처리방침

`치지직 채팅 커스텀`은 치지직 채팅창의 표시 방식과 주 영상 오디오를 사용자의 브라우저 안에서만 조정하는 Chrome/Edge 확장프로그램입니다.

이 확장프로그램은 네이버 또는 치지직의 공식 앱이 아니며, 네이버/치지직과 제휴되거나 승인된 도구가 아닙니다.

## 수집하는 정보

이 확장프로그램은 개인정보, 채팅 내용, 계정 정보, 방문 기록, 결제 정보, 위치 정보, 주 영상의 음성 데이터 등을 수집하지 않습니다.

## 전송하는 정보

이 확장프로그램은 데이터를 외부 서버로 전송하지 않습니다. 주 영상의 음성을 녹음하거나 저장하지 않으며, 개발자 또는 제3자에게 사용자 데이터가 전송, 판매, 공유되지 않습니다.

## 저장하는 정보

닉네임·배지·타임스탬프·채팅 외 패널 표시, 채팅 박스와 색상, 글씨 크기·굵기·색상·자동 대비, 채팅창 모드와 헤더 버튼 표시 설정을 브라우저의 로컬 확장 저장소에 저장합니다. 미니 채팅을 사용하면 창의 위치·크기·배율과 입력 전용·전체화면 표시 설정도 함께 저장합니다. 오디오 개선 사용 여부, 강도 프리셋, 보정 음량과 고급 조절값 및 사용자가 저장한 사용자 프리셋 역시 같은 로컬 확장 저장소에 보관합니다.

채팅창이 처음 표시될 때 설정 적용 전 깜빡임을 줄이기 위해 같은 설정값을 치지직 페이지의 로컬 캐시에 저장할 수 있습니다. 나만 보는 채팅에서 사용하는 표시용 로컬 값은 쿠키를 공유하지 않는 격리된 임시 프레임 안에서만 설정합니다. 이 정보는 모두 사용자의 브라우저 안에서만 사용됩니다.

## 동작 범위

이 확장프로그램은 `https://chzzk.naver.com/*` 안에서 치지직 채팅창의 DOM/CSS 표시와 주 영상의 로컬 오디오 출력만 변경합니다. 나만 보는 채팅·미니 채팅 모드를 선택하면 치지직의 같은 출처 채팅 페이지를 iframe으로 표시하지만, 개발자 서버로 데이터를 보내거나 채팅 내용을 수집하지 않습니다. 오디오 개선은 브라우저의 Web Audio API로 현재 영상 소리를 같은 페이지 안에서 처리합니다. 실제 방송, 서버 상태, 채팅 데이터, 메시지 삭제, 차단, moderation 동작에는 영향을 주지 않습니다.
