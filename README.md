# 치지직 채팅 커스텀

치지직 채팅창의 텍스트 표시와 꾸미기 옵션을 내 브라우저에서만 토글하는 확장 프로그램입니다.

## 채팅창 표시 옵션

치지직 채팅창에서 필요한 항목만 켜고 끌 수 있습니다.

- 닉네임
- 배지
- 타임스탬프
- 채팅 외 패널
- 나만 보는 채팅
- 미니 채팅창

채팅 외 패널 표시를 끄면 후원 랭킹, 승부예측, 스포츠 중계 정보처럼 채팅 메시지가 아닌 패널을 숨깁니다.

## 채팅 외형 옵션

채팅창 외형과 채팅 글자 스타일을 간단하게 변경할 수 있습니다.

- 채팅 박스 색상
- 글씨 크기/닉네임 크기 조정(이모티콘 포함)
- 굵게
- 글자 색상 변경
- 닉네임 색상으로 채팅 표시

닉네임 색상으로 채팅 표시를 켜면 채팅 내용이 닉네임 색상을 따라 표시됩니다.
`글자색 자동 보정`을 켜면 채팅 박스와 글자색이 너무 비슷할 때 읽기 쉬운 색으로 보정합니다.

스타일 프리셋과 나만의 프리셋은 채팅창 설정(기본·나만 보기·미니, 전체화면 전용)을 저장하거나 변경하지 않습니다.

## 나만 보는 채팅

- 실제 채팅은 로그인 없이 그대로 볼 수 있습니다.
- 원래 채팅 입력창과 같은 위치와 모양을 사용합니다.
- 입력창 안내는 `나만 보는 채팅, 실제로 전송되지 않음`으로 한 줄에 표시됩니다.
- 한글 입력 중에도 Enter를 한 번 누르거나 `채팅` 버튼을 누르면 내 화면에만 메시지가 추가되며, Shift+Enter는 줄바꿈합니다.
- 입력 내용은 치지직 원본 입력·전송 경로와 분리된 로컬 입력에서만 처리됩니다.
- 내가 입력한 메시지는 같은 채팅 목록에 실제 채팅처럼 표시되지만 치지직에는 전송되지 않습니다.
- 다른 시청자와 스트리머에게는 보이지 않습니다.
- 다른 사람이 보내는 실시간 채팅은 그대로 표시되며, 새 채팅이 오면 내 로컬 메시지도 일반 채팅처럼 위로 밀려납니다. 로컬 메시지는 최대 100개까지 유지됩니다.
- 닉네임, 시간, 채팅 박스, 굵기, 글자색과 글자 크기 설정이 실제 채팅과 같은 방식으로 적용됩니다.
- 내가 추가한 메시지는 나만 보는 채팅을 끄거나 전체화면으로 전환하거나 페이지를 새로고침하면 사라집니다.
- 전체화면일 때 화면에 표시되지 않습니다.


## 미니 플로팅 채팅창 표시

미니 플로팅 채팅창은 현재 방송의 치지직 채팅을 페이지 안에 작게 띄웁니다.

- 표시 옵션에서 미니 플로팅 채팅창을 켜고 끌 수 있습니다.
- 미니 플로팅 채팅창은 드래그와 크기 조절을 지원하며, 채팅 입력과 전송은 치지직 원래 채팅창 안에서 처리됩니다.
- 채팅 보기 모드는 다른 사람 채팅 목록과 입력칸을 함께 표시합니다.
- 입력 전용 모드는 내가 보낼 채팅 입력/전송 박스만 표시합니다.
- 채팅 외 패널 표시를 끄면 미니 플로팅 채팅창에서도 승부예측, 스포츠 중계 정보 같은 비채팅 패널을 숨깁니다.
- 전체화면에서만 표시를 사용하면 미니 플로팅 채팅창이 전체화면에서만 표시됩니다.
- 최소화 버튼 클릭 시 회색 말풍선 아이콘으로 전환됩니다.
- 나만 보는 채팅 활성화 시 표시되지 않습니다.

## 빠른 전환 버튼

채팅 화면의 작은 버튼으로 설정을 열거나 나만 보는 채팅, 미니 플로팅 채팅창으로 전환할 수 있습니다.

- 나만 보기 전환 버튼은 하단 `채팅` 전송 버튼 바로 왼쪽에 표시됩니다.
- 설정 버튼과 미니 채팅 버튼은 채팅 헤더에 표시됩니다.
- 현재 페이지에서 감지한 테마에 맞춰 화면을 표시합니다.
- 설정 버튼, 나만 보기 전환 버튼, 미니 채팅 버튼은 필요에 따라 켜고 끌 수 있습니다.
