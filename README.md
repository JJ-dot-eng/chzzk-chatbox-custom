# 치지직 채팅 커스텀

치지직 채팅창을 꾸미고 주 영상의 소리를 개선하는 확장 프로그램입니다. 모든 변경은 내 브라우저에만 적용됩니다.

## 파이어폭스 버전

Firefox 데스크톱 140 이상을 지원합니다. 닉네임·랜덤 별명·배지·타임스탬프 표시, 채팅 스타일, 미니 플로팅 채팅창과 오디오 개선을 사용할 수 있습니다.

- **나만 보는 채팅은 Firefox에서 지원하지 않습니다.** 이 기능에 필요한 `credentialless` iframe을 지원하지 않아 모드 선택을 비활성화하고 전환 버튼을 숨깁니다. 이전 설정에 이 모드가 켜져 있어도 기본/미니 채팅을 막지 않습니다.
- Firefox 140~148에서는 채팅 헤더의 설정 버튼으로 팝업을 열지 못할 수 있습니다. 이때 브라우저 도구 모음의 확장 아이콘에서 설정을 여세요.
- Chrome/Edge는 기존 루트 `manifest.json`을 사용하고, Firefox 패키지는 `manifest.firefox.json`을 `manifest.json`으로 넣어 생성합니다.

### 설치

1. Firefox용 ZIP을 풀고 Firefox 주소창에서 `about:debugging#/runtime/this-firefox`를 엽니다.
2. **임시 부가 기능 로드**를 눌러 압축을 푼 폴더의 `manifest.json`을 선택합니다.
3. 치지직 접근 권한이 허용되어 있는지 확인하고, 열려 있던 치지직 페이지를 새로고침합니다.

임시 설치는 Firefox를 종료하면 해제됩니다. 일반 Firefox에서 계속 설치해 두려면 [Mozilla 서명](https://extensionworkshop.com/documentation/publish/signing-and-distribution-overview/)을 받은 XPI가 필요합니다. 생성된 ZIP은 서명 전 개발/심사용 패키지입니다.

### 빌드와 검증

```powershell
npm ci
npm run package:firefox
```

`dist/chzzk-chat-ui-settings-<버전>-firefox/`와 같은 이름의 ZIP을 생성합니다. 같은 버전의 결과물이 있으면 파일명에 시간을 붙여 보존합니다. Chrome/Edge 패키지는 `npm run package`로 생성합니다.

`npm run check`는 구조·문법 및 기존 Chromium 회귀 테스트를 실행합니다(설치된 Edge 또는 `EDGE_PATH` 지정 필요). Firefox 검증은 저장소 안에 테스트용 브라우저를 준비한 뒤 실행합니다. 개인 브라우저 프로필 대신 별도 임시 프로필과 대표 채팅 DOM을 사용합니다.

```powershell
$env:PLAYWRIGHT_BROWSERS_PATH = "$PWD/.tmp/firefox-port/browsers"
node node_modules/playwright-core/cli.js install firefox
npm run test:firefox
```

호환성 근거: [Firefox background](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/manifest.json/background), [credentialless 지원 범위](https://developer.mozilla.org/en-US/docs/Web/API/HTMLIFrameElement/credentialless), [action.openPopup 지원 범위](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/API/action/openPopup).

## 설정창

스타일 프리셋으로 외형을 간편하게 바꾸거나, 각 설정 카드에서 필요한 기능을 조절할 수 있습니다. 빠른 설정은 세부 설정 카드로 통합했습니다.

- 스위치 외에 카드의 글자나 여백을 누르면 세부 설정으로 들어갑니다.
- 오른쪽 토글은 해당 항목의 모든 켜기·끄기 옵션을 함께 변경합니다. 색상·크기·음량 등 조절값은 유지합니다.
- 전체 켜짐은 초록색, 일부 켜짐은 회색과 가운데 손잡이, 전체 꺼짐은 왼쪽 손잡이로 표시합니다. 일부 상태에서 누르면 모두 켜집니다.
- 채팅창 카드는 전체 토글 없이 모드 선택 화면으로 들어갑니다.

## 채팅창 표시 옵션

치지직 채팅창에서 필요한 항목만 켜고 끌 수 있습니다.

- 닉네임
- 배지
- 타임스탬프
- 채팅 외 패널
- 나만 보는 채팅
- 미니 채팅창

채팅 외 패널 표시를 끄면 후원 랭킹, 승부예측, 스포츠 중계 정보처럼 채팅 메시지가 아닌 패널을 숨깁니다.

## 닉네임 변경

보이기 설정에서 랜덤 닉네임을 켜면 채팅 닉네임을 내 화면에서만 다른 이름으로 표시할 수 있습니다. 랜덤 별명과 직접 지정한 이름 중 원하는 방식을 선택할 수 있습니다.

- 랜덤 별명: `초록 여우 1`, `하늘 수달 2`처럼 중복되지 않는 번호를 붙입니다.
- 직접 지정: 닉네임에 `치수`를 입력하면 `치수 1`, `치수 2`처럼 표시합니다.
- 스트리머 배지나 역할 표시가 확인되는 행은 원래 닉네임을 유지합니다.
- 별명이 준비되기 전에는 닉네임 영역만 잠시 숨겨 원래 이름이 깜빡이지 않게 합니다. 채팅 내용은 계속 표시됩니다.
- 같은 탭·채널의 기본, 미니, 나만 보는 채팅은 동일한 별명과 번호를 사용합니다. 새로고침과 모드 전환에도 유지하며 탭을 닫으면 지웁니다.
- 원본 닉네임 문자열을 기준으로 구분하므로 실제 닉네임이 바뀌면 새 번호를 받습니다. 번호는 새 닉네임을 감지한 순서입니다.
- 끄면 원래 이름으로 돌아갑니다. 원본 DOM, 복사한 텍스트와 프로필 메뉴에는 실제 이름이 남을 수 있으며, 다른 사람에게 보이는 이름은 바뀌지 않습니다.

## 채팅 외형 옵션

채팅창 외형과 채팅 글자 스타일을 간단하게 변경할 수 있습니다.

- 채팅 박스 색상
- 글씨 크기/닉네임 크기 조정(이모티콘 포함)
- 굵게
- 글자 색상 변경
- 닉네임 색상으로 채팅 표시

닉네임 색상으로 채팅 표시를 켜면 채팅 내용이 닉네임 색상을 따라 표시됩니다.
`글자색 자동 보정`은 기본으로 켜져 있으며, 채팅 박스와 글자색이 너무 비슷할 때 읽기 쉬운 색으로 보정합니다. 필요하면 설정에서 끌 수 있습니다.

## 오디오 개선

치지직 주 영상의 소리를 더 편안하고 고르게 들려줍니다.

- 오디오 개선을 켜고 끌 수 있습니다.
- `자연스럽게`, `균형`, `강하게` 프리셋을 제공합니다.
- 보정 음량과 세부 설정을 조절할 수 있습니다.
- 기능을 끄면 원래 소리로 돌아갑니다.

## 나만 보는 채팅

- 실제 채팅은 로그인 없이 그대로 볼 수 있습니다.
- 원래 채팅 입력창과 같은 위치와 모양을 사용합니다.
- 입력창 안내는 `나만 보는 채팅, 실제로 전송되지 않음`으로 한 줄에 표시됩니다.
- 입력 내용은 치지직 원본 입력·전송 경로와 분리된 로컬 입력에서만 처리됩니다.
- 다른 사람이 보내는 실시간 채팅은 그대로 표시되며, 새 채팅이 오면 내 로컬 메시지도 일반 채팅처럼 위로 밀려납니다. 로컬 메시지는 최대 100개까지 유지됩니다.
- 내가 추가한 메시지는 나만 보는 채팅을 끄거나 전체화면으로 전환하거나 페이지를 새로고침하면 사라집니다.

## 미니 플로팅 채팅창 표시

미니 플로팅 채팅창은 현재 방송의 치지직 채팅을 페이지 안에 작게 띄웁니다.

- 표시 옵션에서 미니 플로팅 채팅창을 켜고 끌 수 있습니다.
- 미니 플로팅 채팅창은 드래그와 크기 조절을 지원하며, 채팅 입력과 전송은 치지직 원래 채팅창 안에서 처리됩니다.
- 전체화면에서만 표시를 사용하면 미니 플로팅 채팅창이 전체화면에서만 표시됩니다.
- 최소화 버튼 클릭 시 회색 말풍선 아이콘으로 전환됩니다.
- 나만 보는 채팅 활성화 시 표시되지 않습니다.

## 채팅 헤더 버튼

채팅 헤더의 작은 버튼으로 설정을 열거나 나만 보는 채팅, 미니 플로팅 채팅창으로 전환할 수 있습니다.

- 현재 페이지에서 감지한 테마에 맞춰 화면을 표시합니다.
- 설정 버튼, 나만 보기 전환 버튼, 미니 채팅 버튼은 필요에 따라 켜고 끌 수 있습니다.
